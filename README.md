# 👟 Vyrox Shoes

A modern full-stack e-commerce web application for browsing, purchasing, and managing shoes online.

🌐 **Live Demo:** https://vyrox-shoes.vercel.app/

---

## 📌 About the Project

Vyrox Shoes is a full-stack e-commerce platform that provides users with a seamless online shopping experience. Customers can browse products, manage their cart, securely authenticate, place orders, and complete payments using Razorpay.

This project was built to gain practical experience in backend development, REST API design, database management, authentication, and integrating a frontend with a backend.

---

## ✨ Features

* User Registration & Login
* JWT Authentication
* Secure Password Hashing using bcrypt
* Product Catalog
* Category-wise Products
* Product Details
* Shopping Cart
* Order Management
* Product Reviews & Ratings
* Razorpay Payment Integration
* Responsive User Interface

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Vineet2007-cyber/vyrox_shoes.git
```

### Install dependencies

```bash
cd backend
npm install
```

### Configure Environment Variables

Create a `.env` file and add the required environment variables.

Example:

```env
PORT=5000

MYSQL_HOST=your_host
MYSQL_USER=your_username
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=your_database

JWT_SECRET=your_secret_key

RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```

### Start the server

```bash
npm start
```
